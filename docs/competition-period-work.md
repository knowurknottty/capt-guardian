# Competition-Period Work

CAPT Guardian / CAPT Relay is a deliberately scoped public derivative informed by pre-existing private CAPT architecture. The private CAPT repository is not copied or published here.

## Work created for this hackathon derivative

- standalone Guardian authority kernel;
- canonical action-digest binding;
- single-use human approval semantics;
- denial and post-approval tamper rejection;
- typed evidence/provenance records;
- execution and receipt ledger structures;
- separately authenticated, digest-bound human approval request/decision channel;
- Alexa+-compatible MCP tool surface;
- MCP `2025-11-25` Streamable HTTP compatibility tests;
- real Node HTTP server and Host/Origin guards;
- local MCP latency benchmark;
- competition rules matrix, threat model, and friction log.

## Pre-existing concepts reused

CAPT concepts such as explicit authority, human approval, provenance, receipts, model/tool authority separation, and governed execution predate this hackathon. This repository independently implements only the narrow public primitives intentionally released for CAPT Guardian.

This file will be updated through submission so judges can distinguish pre-existing architectural ideas from competition-period implementation work.
